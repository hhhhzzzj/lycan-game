> “当前项目是一个AI狼人杀游戏引擎后端。底层逻辑存在严重的Bug，我为你整理了三大核心问题，并附带了具体的日志证据。请根据这些证据，帮我定位并修改相关代码：
> **一、 状态机未同步存活列表（导致幽灵互动与记忆断层）**
> * **代码定位方向：** 负责组装角色 `System Prompt`、维护 `GameState`（存活玩家列表）的代码。
> * **核心罪证：**
> * **【证据1 - 第二局 第2天白天】：** 1号预言家在夜间已死，3号狼人第1天已被放逐。但2号、4号村民在第2天发言时仍说“跟着1号走”，6号甚至号召“今天先出3号”。这证明后端进入新的一天时，没有将死亡状态注入Prompt。

> * **修改要求：** 在拼接Prompt时强制注入当前存活状态（如：“当前存活：X,Y。死亡：Z”）；在接收投票/刀人请求的接口增加拦截器，选中死亡玩家直接阻断并Retry。

> **二、 大模型结构化输出解析Bug（思维与动作严重撕裂）**
> * **代码定位方向：** 负责处理 LLM 返回的 JSON 解析、工具调用（Tool Calling）以及动作执行的类。
> * **核心罪证：**
> * **【证据1 - 第二局 第2天夜晚】：** 5号女巫被刀，`<thinking>` 明确推导：“我决定使用解药，这是保护自己的最佳策略”。但最终动作输出却是：“→ 不使用任何药”，导致自我淘汰。

> * **修改要求：** 优化 JSON 提取的 Prompt，加入强约束：“Action 必须严格匹配 Thinking 的最终决定”。如果在用 Spring AI 或 LangChain4j，请改用严谨的枚举（Enum）配合 Structured Output 来约束模型，并增加校验拦截。
